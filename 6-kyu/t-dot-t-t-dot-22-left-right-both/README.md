Both?</a></h2><h3>6 kyu</h3><h3 id="task">Task</h3><p>You have a keyboard like this:</p><p><img alt="!!" src="https://upload.wikimedia.org/wikipedia/commons/thumb/5/51/KB_United_States-NoAltGr.svg/500px-KB_United_States-NoAltGr.svg.png"></p><p>You strictly abide by the typing standard. That is, use the left hand hit the left part of  the keyboard, use the right hand hit the right part of keyboard, the boundary is:</p><pre><code> L     1.....5 | 6.....0     R E     Q.....T | Y.....P     I F     A.....G | H.....'     G T     Z.....B | N...../     H          SPACEBAR           T</code></pre><p><strong>Note:</strong> the <code>SpaceBar</code> is an exception, because both hands can be used to hit it.</p><p>Complete the function that accepts a string. </p><ul><li>if the string can be typed by the left hand only, return <code>"Left"</code></li><li>if the string can be typed by the right hand only, return <code>"Right"</code></li><li>if both hands are needed to type the string, return <code>"Both"</code></li><li>if the string is empty or contains only spaces, return an empty string <code>""</code></li></ul><p>Please remember that we are discussing the keyboard above and not any other one. The reason is that we need a standard.
